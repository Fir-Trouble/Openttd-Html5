# OpenTTD-Html5

An unofficial HTML5/WebAssembly port of OpenTTD, built on the `master-g1b71d4c883` branch.

## Controls & Features
* **CTRL + SHIFT + S:** Opens the custom save downloader/uploader (since standard OpenTTD doesn't natively support this on the web)
* Everything else works just like the standard game. Find out more at [OpenTTD.org](https://www.openttd.org)
